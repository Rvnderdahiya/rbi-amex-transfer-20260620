# FIU India Review Package

Cutoff: 5 November 2026. One inventory sheet, seven requested fields.

## Download And Open

1. Download all three ZIP files using each file's Download button:
   `FIU_Inventory_Audit.zip`, `FIU_Originals_01.zip`, `FIU_Originals_02.zip`.
2. Extract each ZIP into the **same chosen parent folder**. Each contains a
   `FIU_India` folder. Merge that folder when Windows asks. Do not put each ZIP
   inside a different archive-named subfolder. These are ordinary independent
   ZIPs, not split parts; no assembly script, Git clone or Git LFS is needed.
3. Open `FIU_India/FIU_Inventory.xlsx`. Keep it beside `Originals`, `Exceptions`
   and `Audit`. Clicking a document title opens its supplied file. Additional
   attachments are listed in the title note and `Audit/Inventory.csv`.

The separate workbook is available for preview, but does not itself contain PDFs.

## Contents

- 213 distinct source announcements, after consolidating 18 repeat appearances.
- 31 supplied-phrase exclusions, leaving 182 inventory entries.
- 183 original PDFs (942 pages) and one original XLS, organised by subject.
- One portal-only item offers no attached instrument; its saved listing extract
  is explicitly labelled. No retained published attachment original is missing.
- A broken FINGate memorandum link was recovered from the same FIU filename
  without an extra space; its original page and 11 April 2023 date were verified.
- Exclusions, every source occurrence/URL, file hashes, date evidence and checks
  are in `Audit`. Publisher PDF structural warnings are preserved and disclosed.

The workbook passed normal-load native Excel checks before and after extraction:
1,274 cells and 364 hyperlinks. All originals match their captured hashes, and all
PDF pages rendered in two engines. Dates are not inferred from filenames/deadlines.
147 full dates, five partial dates and 30 unestablished dates remain distinguished.

AEBC relevance is a preliminary document-scope assessment, not a legal approval
or an active-only certification. Full-text/OCR screening and targeted visual review
do not amount to a human word-for-word certification of all pages. The four literal
exclusions were not broadened to remove every recruitment/procurement notice.
Read `READ_ME.txt` before use. Other source packages on this branch are unchanged.
